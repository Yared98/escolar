# Arquivo Histórico: Refatoração de Navegação

Estes documentos pertencem ao marco histórico de refatoração da navegação do frontend (Sidebar baseada em URLs com query params `?tab=`, padronização das seções e suíte de testes de navegação em `tests/e2e/`).

- `PROJECT.md`: Blueprint histórico da arquitetura de navegação e contratos de interface do frontend.
- `TEST_INFRA.md`: Arquitetura e camadas da suíte de testes de navegação.
- `TEST_READY.md`: Comandos originais de execução e checklist de cobertura da suíte de navegação.

> **Nota:** A fonte canônica de especificações e regras de negócio do sistema é `openspec/`.
