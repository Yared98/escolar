# Como se conectar às APIs do Itaú

Fonte: https://devportal.itau.com.br/como-se-conectar-as-apis-itau

Como se conectar às APIs do Itaú

Use este guia para configurar seu ambiente e realizar sua primeira integração com as APIs do Itaú.



Boas-vindas

    Bem-vindo ao Portal do Desenvolvedor do Itaú.

    Aqui você encontra os principais passos para preparar seu ambiente, gerar suas credenciais e realizar sua primeira chamada a uma API.

    Cada etapa da jornada direciona para a documentação correspondente, com as orientações necessárias para concluir sua integração com segurança.

    Jornada de integração

    Siga as etapas abaixo para se conectar às APIs do Itaú:

    1. Conheça os produtos disponíveis

    Entenda quais APIs atendem às necessidades da sua empresa e como contratar os produtos com seu especialista Itaú.

    Acesse: Conheça o Portal

    2. Prepare seu ambiente

    Verifique os requisitos necessários para se conectar aos ambientes do Itaú.

    Acesse: Pré-requisitos para se conectar ao ambiente Itaú

    3. Entenda os conceitos de segurança

    Conheça as boas práticas para proteger suas credenciais e utilizar as APIs com segurança.

    Acesse: Boas práticas para o uso de credenciais

    4. Gere suas credenciais e certificado

    Obtenha as credenciais da aplicação e emita o certificado dinâmico necessário para autenticação.

    Acesse: Como obter as credenciais e gerar o certificado dinâmico

    5. Faça sua primeira chamada

    Valide sua configuração realizando uma chamada para uma API do Itaú.

    Acesse: Como fazer a primeira chamada a uma API
